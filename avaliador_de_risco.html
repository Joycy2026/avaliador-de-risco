Regras da matriz

TOP 25

🔴 Alto — Dentro das recomendações + dentro da estatística/sem dados + TOP 25 + Ótimo/Bom/Neutro.
🟡 Médio — Dentro das recomendações + dentro da estatística/sem dados + TOP 25 + Excelente.
🟢 Baixo — Dentro das recomendações + dentro da estatística/sem dados + TOP 25 + Aceite.
🔴 Alto — Fora das recomendações (tabulado como sem dados) OU fora da estatística + TOP 25 + Excelente/Aceite.

FORA DO TOP 25

🔴 Alto — Fora das recomendações (tabulado como sem dados) OU fora da estatística + FORA TOP 25 + Neutro.
🔴 Alto — Programa sem estatística E sem recomendação + FORA TOP 25 + Neutro. Essa regra deixa de se aplicar quando “sem recomendações” é considerado “dentro”.
🟡 Médio — Fora das recomendações (tabulado como sem dados) OU fora da estatística/sem dados + FORA TOP 25 + Bom/Ótimo.
🟢 Baixo — Fora ou dentro das recomendações + fora ou dentro da estatística/sem dados + FORA TOP 25 + Excelente/Aceite.
🟢 Baixo — Dentro das recomendações + dentro da estatística + FORA TOP 25 + Neutro/Bom/Ótimo.
